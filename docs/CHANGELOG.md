# 更新日志

## 1.3.6

新增：支持设置三餐提醒通知。
新增：统计页增加饮食规律分析。
新增：统计页增加饮食建议卡片。

优化：支持查看每天的用餐时间详情。
优化：识别失败时展示更具体的错误原因。

## 1.3.5

优化：检查更新现在使用gitee，下载更快。
优化：分层应用图标。
优化：外观页增加配色实时预览。
优化：关于页展示应用图标与版本信息。
优化：文本选择菜单样式。

## 1.3.4

新增：支持桌面长按图标快捷方式。
新增：识别失败后支持一键重试。
新增：权限管理页支持清理应用内照片缓存。

优化：食物日志改为数据库存储，读写更稳定。
优化：开启代码与资源压缩，减小安装包体积。

## 1.3.3

新增：支持新建、编辑和删除预设食物。
新增：手动录入支持完整编辑营养与食物成分。
新增：编辑记录页可将当前记录加入预设或取消预设。
新增：热量目标页增加填写个人信息入口。

优化：预设选择改为独立步骤页，便于管理常用食物。
优化：二级步骤返回时，若存在未保存内容会先确认。

## 1.3.2

新增：支持在独立页面编辑已记录的食物。
新增：支持添加、删除和更换食物元素。
新增：关于页面增加意见与反馈入口。

优化：统一数据库匹配流程。

修复：权限管理页面在部分设备上打开时崩溃的问题。
修复：食物成分更换无法使用usda数据的问题。

## 1.3

新增：通知栏实时进度，目前支持HyperOS3.3/ColorOS16及以上版本。
新增：食物识别离开应用后仍可继续处理。
新增：识别阶段进度展示。
新增：权限管理页面，统一管理各权限。
新增：检查更新入口。

优化：统一图片、文字、手动录入和菜品替换的识别任务处理流程。
优化：拍照识别后可保存到相册。
优化：默认配置调整为deepseek（已有配置不变）。

修复：长按输入框上下文菜单风格统一。
修复：开屏画面颜色统一。
修复：个人信息页未修改全部信息时不显示录入按钮。
