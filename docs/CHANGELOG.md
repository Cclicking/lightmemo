# 更新日志

## 1.5.1

新增 智能识别模式，实现聊天式食物录入。
新增 本机 MCP 服务，支持小爱查询摄入与文字录入。
新增 健身目标，提供对应的热量与营养素推荐。
新增 每日目标支持从今天起生效、也可选择覆盖历史目标。
新增 连接 Health Connect 后可展示热量差卡片。
新增 统计卡片管理，支持拖动排序、隐藏和恢复展示。
新增 USDA Foundation 与 FNDDS 离线营养数据，数据库页面支持分别筛选。

优化 MCP 服务页提供电池优化、自启动和省电设置入口。
优化 减少 MCP 空闲线程和小组件后台数据读取。
优化 数据库检索统一常用单复数和食物别名，并结合原名及中英文检索词召回候选。
优化 自动匹配校验食物身份、生熟和烹饪方式，存在冲突或信息不足时保留候选供确认。
修复 常用词“熟鸡肉块、青椒、橘子”的检索遗漏，以及全角括号食物别名未生效的问题。
修复 西兰花与油菜薹、黄瓜与海参、鸡肉与素鸡因英文名称共享单词而混淆的问题。
修复 将水、食用油、牛奶、汉堡胚等配料误匹配成包含该配料的整道菜的问题。
修复 土豆与红薯、红薯与薯叶、普通肉类与香肠培根，以及土豆可食部分与土豆皮的混淆。
优化 原始食物名独立校验自动匹配；个人记忆和同图缓存复用时拦截已知食物身份冲突。

修复 数据库匹配在部分情况下无法回退到中文食物数据
修复 数据库有时误匹配无关食物的问题。
修复 桌面快捷方式图标的圆形外观与缩放比例问题。
修复 忽略建议按钮与底部弹层样式不一致的问题。
